# Owners

One area per bot. Touch another bot's area only by agreement, in a PR that bot reviews.

| Area | Owner | Branch prefix |
|---|---|---|
| Audio: music, SFX, the mute button and the audio engine | Forge Runner Audio | `audio/` |
| Layout, rendering and performance: canvas sizing/fit, DPR, drawing, frame rate, mobile/orientation | Forge Runner Mobile | `mobile/` |
| Gameplay, integration and everything else: rules, enemies, scoring, beacons/stats, share/challenge links, Lambda handler, build, CI | Forge Runner Dev | `dev/` |
